# 分析タブ（演題の地図）の作り方と引き継ぎメモ

page.html の3つ目の画面「分析」（旧名「地図」）のデータを作るスクリプト一式。
別セッションで作り直すときは、このファイルを最初に読むこと。

## 何をしているか（2026-11-01 時点）

演題ごとに290次元のベクトルを作り、それを2次元に縮めて地図にしている。

1. **トピック 34次元**（主役）
   - `concepts.py` の `VOCAB`（34種類の研究トピック）と `C`（演題ごとのトピック、1〜4個）。
   - どちらも Claude が演題名（＋セッション名）を見て付けた。人手のラベルなので、ここの付け方が結果を大きく左右する。
   - 0/1 に IDF（珍しいトピックほど重い）を掛け、長さを1にそろえる。
2. **タイトル埋め込み 256次元**（補助）
   - 英語タイトルを WordLlama（`l2_supercat`、256次元）で埋め込み、長さ1。
   - 抄録はまだ使っていない（未公開のため）。
3. **結合**：`[トピック×1.0, タイトル×0.45]` をつなげて、もう一度長さ1にそろえる。
   - 近さ（コサイン類似度）への影響はおよそ トピック83%：タイトル17%。
   - **0.45 はデータから最適化した値ではない。** WordLlama 単独の類似度が頼りにならなかったので、補助として効く程度に Claude が目で決めた値。重みを変えた比較検証はしていない（ユーザー了承済み、2026-11-01「このままでよい」）。
   - 根拠を持たせたくなったら：重み0〜1ごとに「同じシンポジウムの演題が近い演題上位5件に入る割合」や、地図の安定度を測る案がある。
4. **2次元化**
   - 似ている順 ＝ t-SNE（cosine、perplexity 14、init pca、random_state 7、max_iter 2500）。近いもの同士がかたまるだけで、軸の向きや塊どうしの距離には意味がない。
   - 全体傾向 ＝ PCA（2成分）。軸に意味がある（下記）。
5. **まとまり（色分け）**：同じ290次元で凝集型クラスタリング（cosine、average linkage）、K=11。名前は Claude が中身を見て付けた（`build_map.py` の `NAMES`）。**注目タグは使っていない**（分類はデータから。注目タグは後から重ねて見るためのもの、というユーザー方針）。
6. **近い演題**：290次元のコサイン類似度の上位5件（`nb`）。同じシンポジウムの演題はトピックがほぼ同じになり、近く出やすい。
7. **学会の注目度 att**（今は画面で未使用）：トピックごとに「演題×講演の種類の重み（招待・教育講演3、シンポジウム2、教育セッション1.5、一般口演1、ポスター0.5）」を足し上げ、演題はそのトピックの平均を0〜1の順位にしたもの。「興味×注目度」の4区画表示に使っていたが、2026-11-01 にその表示は削除した（描画コードは page.html に残置、ボタンなし）。

## 全体傾向（PCA）の軸の意味

`pca_axes.py` で、各軸のスコアと各トピック（0/1）の相関を見て決める。2026-11-01 時点（シンポ等128件＋架空ポスター14件）：

- 説明率は PC1 7.1%＋PC2 6.7% ＝ 約14%。2軸ではばらつきのごく一部しか表せない。「大きく2本で分かれている」とは言えない。
- PC1（横、右が正）：右側は「遺伝カウンセリング」(r=0.81)・「倫理」(0.57) が強く決めている。左側は疾患モデル・創薬・希少疾患・GWAS が弱く (−0.24〜−0.27) 並ぶだけ。→ 実態は「遺伝カウンセリング・倫理の演題か、それ以外か」。
- PC2（縦、上が正）：上は「希少疾患」(0.80)・「小児」(0.45)、下は「腫瘍」(−0.46)・「遺伝性がん」(−0.39)・「GWAS」(−0.36)。
- 画面の軸ラベルは今「← 基礎・創薬／臨床・カウンセリング →」「希少疾患・小児 →／← がん・GWAS」。左の「基礎・創薬」は弱い相関からの言い換えで正確ではない（直すなら「その他」など。ユーザーには指摘済み、未修正）。
- ポスターの本番データ（約200件）が入ると軸の意味は大きく変わる見込み。作り直したら `pca_axes.py` を流し、page.html の軸ラベル（`st.mode==='pc'` の `T(...)` 4つ）を書き換える。

## 作り直し手順

```
cd tools/map
pip install wordllama==0.4.0.post1 scikit-learn numpy --break-system-packages
# WordLlama の重みはパッケージに同梱。Hugging Face はこの環境から届かないので、同梱物を cache_dir にコピーして使う
P=$(python3 -c "import wordllama,os;print(os.path.dirname(wordllama.__file__))")
mkdir -p wlcache/weights wlcache/tokenizers
cp $P/weights/l2_supercat_256.safetensors wlcache/weights/
cp $P/tokenizers/l2_supercat_tokenizer_config.json wlcache/tokenizers/
python3 build_map.py 11      # → mapdata.json（クラスタ構成を表示。名前 NAMES は中身を見て付け直す）
python3 pca_axes.py          # → 軸の意味
```

- 入力：`tt_keep.json`（時間割の演題。CN は除外）、`pv_rows.json`（ポスター。**今は架空のサンプル14件**）。
- 新しい演題を足したら `concepts.py` の `C` にトピックを付ける（未付与だと assert で止まる）。
- 出力 `mapdata.json` を page.html の `<script type="application/json" id="mapdata">…</script>` の中身と差し替える。
- page.html の決まり：スクリプト内に「//」を書かない（Apps Script の前処理で壊れる）。

## 抄録・ポスター公開後にやること

- 埋め込みをタイトルから抄録に替える（英語抄録）。トピックも抄録で付け直す。
- ポスター本番（約200件）を `pv_rows.json` に。点は約330件（今の約2.3倍）になる。
- まとまり数 K、名前、PCA の軸ラベルを見直す。
- 学会直前に配置を固定する（以後は作り直さない）方針。

## 画面側の仕様（page.html の分析画面）

- 表示切替：似ている順（t-SNE）／全体傾向（PCA）。
- 点：シンポジウム等＝丸、ポスター＝小さい丸（ひし形は廃止）。拡大しても点・文字はほとんど大きくならない（z^-0.85 で縮小）。
- タップは近い点に吸着（スマホ26px、PC12px以内）。PCは点に重ねると横にフロート（クリックで詳細、「フロート」ボタンで出す・出さない切替）。
- 外側の丸：紫＝すいすいの印、緑＝ATの印。「すいすい」「AT」ボタンで表示切替。閲覧用リンクには出ない。
- 地図の下の欄：「内容のまとまり｜注目タグ」を切替。まとまりは地図上では番号の丸（①〜⑪）、押して強調したときだけ名前を表示。注目タグは押したタグに当たる演題を黒い縁で強調。強調は開いている側だけ。
- 状態は localStorage `jshg2026map` に保存（表示、層、タグ、欄、印の丸、フロート）。
