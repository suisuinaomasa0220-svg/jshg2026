# 地図タブのデータ作成

- `concepts.py`：演題ごとの研究トピック（Claudeが付与、地図の主な信号）
- `build_map.py`：トピック（IDF重み）＋ WordLlama 埋め込み（英語タイトル）を結合 → t-SNE / PCA で2次元化、凝集型クラスタリングで11のまとまり、各演題の近い演題5件
- 出力 `mapdata.json` を page.html の `<script id="mapdata">` に埋め込む
- 抄録公開後は、抄録で作り直す
- 学会の注目度（att）：トピックごとに「演題数×講演の種類の重み（招待・教育講演3、シンポジウム2、教育セッション1.5、一般口演1、ポスター0.5）」を足し上げ、演題はそのトピックの平均。0〜1の順位に変換
- 興味×注目度の表示：横＝注目タグの当たり数（＋自分の印）、縦＝att。区切りは「当たり1以上」と「att 0.5」

## 全体傾向（PCA）の軸ラベル

page.html の地図で、PCA の軸の両端に名前を付けている（2026-11-01 時点の見立て）。
各軸のスコアと各トピック（0/1）の相関で決めた。PC1: 正＝遺伝カウンセリング・倫理・生殖、負＝疾患モデル・治療・希少疾患・GWAS。PC2: 正＝希少疾患・小児、負＝腫瘍・遺伝性がん・GWAS。2軸の説明率は約14%（7.1%＋6.7%）。
作り直したら相関を再計算し、page.html の軸ラベルと説明文（地図の mnote）を書き換えること。
